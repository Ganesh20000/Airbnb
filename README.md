# Airbnb Data Analysis Project

This repository contains my project on **Airbnb Data Analysis**.  
The project focuses on exploring Airbnb listings, cleaning the dataset, analyzing patterns, and drawing insights that could help hosts, travelers, and the platform.

---

## What I Did in This Project

1. **Data Cleaning & Preprocessing**
   - Handled missing values in the dataset.
   - Removed duplicate and inconsistent records.
   - Treated outliers in price, reviews, and availability columns.

2. **Exploratory Data Analysis (EDA)**
   - Analyzed distribution of listings across neighborhoods and cities.
   - Studied price variations with respect to location, room type, and availability.
   - Visualized trends in reviews, host activity, and booking behavior.

3. **Feature Engineering**
   - Extracted useful variables from raw data (e.g., average reviews per month).
   - Encoded categorical variables for modeling.

4. **Insights & Visualization**
   - Identified top neighborhoods with the highest number of listings.
   - Found key factors that influence Airbnb prices.
   - Created visualizations for better understanding of supply and demand trends.

5. **Modeling (if included)**
   - Built predictive models to estimate Airbnb listing prices.
   - Evaluated performance using RMSE and R² score.
